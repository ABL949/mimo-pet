# MIMO 桌宠 · mimo-pet

一款 Android 悬浮桌面宠物：把二次元角色养在手机桌面上，可拖动、可点击互动、
可自主走动，支持双形象与三档尺寸。个人学习用途的二创同人项目。

> ⚠️ 本项目为**非官方二创同人**，与小米公司及其品牌形象无关，仅供个人非商业使用，
> 详见 [NOTICE.md](NOTICE.md)。

仓库地址：[GitHub 主仓](https://github.com/ABL949/mimo-pet) · [Gitee 国内镜像](https://gitee.com/ABL949/mimo-pet)

## 功能一览

- **双形象切换**：兔娘 / 萌版 两款立绘，在设置页点选即可切换
- **三档尺寸**：小 / 标准 / 大
- **眨眼与呼吸浮动**：待机时自动眨眼、上下轻浮动
- **随机方向游走**：待机时上下左右斜向随机走动，始终留在屏幕内（可关闭）
- **贴边半隐藏**：拖到边缘藏入超过三成才吸附；待机时小概率自己贴边，一段时间后自动游回；点一下拉回
- **触摸拖动**：原生触摸拖动，跟手不卡顿
- **五种互动状态**：待机浮动、眨眼、开心跳跃、犯困打盹、害羞摇摆
- **安静模式**：只做动作，不冒气泡
- **穿透模式**：桌宠不拦截触摸，遮挡位置可正常点击屏幕上的应用
- **按需启动**：不点「启动桌宠」不会在后台自动运行

## 安装

1. 在仓库 Releases 页面下载最新版 `mimo-pet-v3.1.2.apk`（GitHub 与 Gitee 镜像均可）
2. 允许系统「安装未知来源应用」后点击安装
3. 打开 App → 首次使用开启**悬浮窗权限** → 点「启动桌宠」

### 所需权限

| 权限 | 用途 |
| --- | --- |
| 显示在其他应用上层（悬浮窗） | 让桌宠悬浮在桌面和其他 App 之上 |
| 前台服务 | 保持桌宠在后台持续运行 |
| 通知 | 显示桌宠运行中的常驻通知 |

## 设置项说明

| 设置 | 说明 |
| --- | --- |
| 形象 | 兔娘 / 萌版 二选一 |
| 大小 | 小 / 标准 / 大 三档 |
| 安静模式 | 开启后角色只做动作，不再冒气泡 |
| 穿透模式 | 开启后桌宠不拦截触摸，不影响点按被遮挡的应用 |
| 自主走动 | 开启后待机时在屏幕内自由游走，可上下左右移动 |

修改任意设置后，若桌宠正在运行会自动重启生效。

### 命令行编译（可选，面向开发者）

依赖：JDK 17、Android SDK Build-Tools 34、Android Platform 34。

```bash
# 1. 编译资源
aapt2 compile --dir app/res -o res.zip

# 2. 链接生成基础 APK（含 assets）
aapt2 link -o base.apk -I $ANDROID_HOME/platforms/android-34/android.jar \
  --manifest app/AndroidManifest.xml -A app/assets -R res.zip \
  --min-sdk-version 23 --target-sdk-version 34

# 3. 编译 Java
javac -source 8 -target 8 -cp $ANDROID_HOME/platforms/android-34/android.jar \
  -d classes app/java/com/mimo/pet/*.java

# 4. 转 dex
d8 --release --lib $ANDROID_HOME/platforms/android-34/android.jar \
  --min-api 23 --output dexout classes/com/mimo/pet/*.class

# 5. 合并 dex、对齐、签名
zip -uj base.apk dexout/classes.dex
zipalign -f 4 base.apk aligned.apk
apksigner sign --ks your.keystore --out mimo-pet.apk aligned.apk
```
